# TILIEK

A web-based platform for monitoring and analyzing news issues.

## About

TILIEK merupakan proyek pengembangan platform berbasis web yang berfokus pada pemantauan dan analisis isu pemberitaan di Indonesia.

Proyek ini dikembangkan untuk mengumpulkan data berita dari berbagai sumber media daring dan mengolahnya menjadi informasi yang dapat membantu memahami perkembangan isu serta tren pemberitaan.

## Current Development

Pengembangan TILIEK dilakukan secara bertahap. Beberapa bagian yang sedang dan akan dikembangkan meliputi:

- Pengumpulan berita melalui RSS Feed.
- Penyimpanan data berita.
- Text preprocessing.
- Analisis sentimen.
- Pengelompokan berita berdasarkan topik.
- Visualisasi hasil analisis.

## Data Sources

Sumber berita yang saat ini digunakan dalam proses pengumpulan data:

- Detik
- CNN Indonesia
- Republika

## Technology

Teknologi yang digunakan dan sedang dieksplorasi dalam pengembangan proyek:

- Python
- SQLite
- Feedparser
- BeautifulSoup
